# AI Disclosure

We used AI tools during this project to research on eye physiology and synthetic gaze datasets, project planning, code generation and debugging, test writing, rendering and validation runs, and drafting documentation and slide text.

Our own work: choosing the approach and features, writing the build brief with the requirements and acceptance checks, reviewing the code, renders and metrics, and catching problems. For example, we flagged that the 51 % glint figure would mislead judges and asked for a ray-cast visibility
test. We also required the deck to follow the official submission template and the package to be published in a GitHub release. All final decisions on what was submitted were ours.

All results in the README, validation report and slides come from code run in this repository.
